# Srimoyee Bera — Portfolio

Personal portfolio site: QA Automation Engineer (Playwright, Selenium WebDriver, SDET).

**Live:** https://srimoyeebera.github.io

Plain HTML, CSS and JavaScript — no build step. Light/dark mode, responsive, accessible (semantic HTML, keyboard focus styles, reduced-motion support).

## Update the content
- Text: edit `index.html`
- Resume: replace `assets/Srimoyee_Bera_Resume.pdf` (keep the same file name)
- Photo: add `assets/photo.jpg` and follow the comment above the avatar in `index.html`

## Preview locally
Open `index.html` in a browser, or run `npx serve .`
